PROJECT CHECK

Before you submit.

Use these checks to audit the frontend against the Project 1 brief.

Is the interface mobile-first?

Yes. The base layout is designed for small screens and expands using responsive breakpoints.

Does it use semantic HTML?

Yes. The page uses header, nav, main, section, article and footer.

Where are Grid and Flexbox used?

Grid handles major page layouts while Flexbox handles navigation, buttons and component alignment.

What JavaScript is included?

JavaScript handles the mobile menu and resource filtering.
